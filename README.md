# chart-creator

An [Open Notebook](https://open-notebook.ai) **creator** plugin: turns notebook
content into a chart, designed as a [Flint](https://github.com/microsoft/flint-chart)
unified input and rendered client-side with **Vega-Lite**, **ECharts**, or **Chart.js**.

- The LLM emits a Flint input (`{data, semantic_types, chart_spec}`) as the
  `flint.v1` artifact schema; the shipped self-contained view bundle compiles it with
  Flint's `assemble*` functions and renders it (fully offline).
- The user picks a **library** and **chart type** in the creation modal, or leaves either
  on **Auto** and lets the model choose the best fit for the data. Browse chart examples
  in the [Flint gallery](https://microsoft.github.io/flint-chart/#/gallery).
- Implements the [`open-notebook-creator-sdk`](https://github.com/Notebooker-ai/open-notebook-creator-sdk) `BaseCreator` contract; registers under `open_notebook.creators`.

## Model roles

| role | kind | requires |
|------|------|----------|
| `text` | language | `structured_json` |

## Config

| field | default | notes |
|-------|---------|-------|
| `theme` | "auto" | auto/light/dark; "auto" follows the app's light/dark mode |
| `engine` | Auto | discriminated by `library` (auto / vega-lite / echarts / chartjs); each library exposes its own `chart_type` enum, or `auto` |
| `count` | 1 | how many to generate (1–6); each uses a different design/emphasis |

## View bundle

The offline view at `src/chart_creator/view/index.html` is generated by an esbuild build
that bundles Flint + Vega-Lite + ECharts + Chart.js. Source lives in `view-src/`:

```bash
cd view-src
npm install
npm run gen     # regenerates src/chart_creator/chart_types.py from Flint's template defs
npm run build   # bundles the renderers into src/chart_creator/view/index.html
```

Both outputs are committed and ship in the wheel; only rebuild when bumping `flint-chart`
or editing `view-src/main.js`.
